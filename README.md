# OOP Python Assignments (HW 1–3)

Three small OOP exercises implemented in **pure Python**.  
Each assignment lives in its own folder with a `main.py` you can run directly.

## Structure
- `HW1_VacationPackage/` — Abstract base + two concrete packages (Adventure/Relaxation)
- `HW2_HotelTour/` — Abstract base with cost calculation (Hotel/Tour with discount)
- `HW3_PatientsDoctors/` — Inheritance with `Person` → `Patient` / `Doctor`

## Run
```bash
# HW1
python HW1_VacationPackage/main.py

# HW2
python HW2_HotelTour/main.py

# HW3
python HW3_PatientsDoctors/main.py
```
